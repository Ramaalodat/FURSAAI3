# Fursa AI | فرصة — النموذج المتوازن

هذه الحزمة مستقلة وتستخدم نموذجًا متوازنًا واحدًا. مقارنة الخوارزميات جزء من التدريب وليست نسخًا مختلفة للمشروع.

## تشغيل الموقع مباشرة
1. فكّي الضغط وافتحي مجلد Fursa_AI_Balanced كاملًا في VS Code.
2. استخدمي Python 3.11 أو 3.12، وشغّلي من Terminal داخل المجلد:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.port 8502
```

3. افتحي http://localhost:8502 . النموذج المدرّب مرفق، ولا تحتاجين إعادة التدريب.
4. هذه الحزمة تفتح على المنفذ 8502 لتفادي الخلط مع موقع يعمل على 8501. تأكدي أن Terminal داخل مجلد Fursa_AI_Balanced.

## النوتبوك
افتحي Fursa_AI_Balanced.ipynb واختاري نفس بيئة Python من Select Kernel. شغّلي الخلايا بالترتيب لإعادة التجربة. البحث المتداخل يستغرق عدة دقائق. آخر خلية تشغّل الموقع محليًا. أوقفيه بـapp_process.terminate() إذا بدأته من تلك الخلية.

المراحل: فهم الداتا، التخريب التعليمي والتنظيف، EDA، Feature Engineering، تجهيز Milestone 3، مقارنة الخوارزميات وضبطها، تقييم متداخل، حفظ النموذج، منحنى التعلم والتفسير، K-Means استكشافي، ثم الموقع.

## معنى النتائج
الاختيار بمتوسط Balanced Accuracy داخل البحث. نتائج nested_cv تخص طيات التحقق الخارجية داخل التدريب، وهي التقييم الأساسي. بيانات الاختبار المرجعية سبق فحصها أثناء التطوير، فلا تمثل اختبارًا خارجيًا جديدًا. لا تستخدم في الاختيار أو ضبط العتبة.

المؤشر = predict_proba لفئة Placed × 100، وليس احتمال توظيف معايرًا أو قياس جاهزية مُعتمدًا. خطط المهارات قواعد تعليمية معلنة والمحاكاة غير سببية. مصدر البيانات Kaggle بحسب وصف المشروع، ولم نتحقق من كيفية توليدها أو تمثيلها للأردن؛ أضيفي رابط المصدر ورخصته بعد التحقق منهما.

النموذج يستخدم 12 مدخلًا وميزتين مشتقتين. الداتا الأصلية نظيفة، والتخريب محاكاة تعليمية معلنة. لا نستخدم الراتب أو الشركة أو درجة التوظيف الجاهزة، ولا نقص قيم IQR الصحيحة تلقائيًا. لا يوجد assert في النوتبوك.
